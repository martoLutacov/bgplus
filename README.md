# ТВ БГ+ — рекламна лендинг страница

Next.js (App Router) + Tailwind CSS v4 + Framer Motion.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

## Къде какво се променя

| Какво | Файл |
| --- | --- |
| **Цени: пакети, спонсорства, пълен ценоразпис, бюджети** | `data/pricing.ts` |
| Текстове, контакти, статистики, ЧЗВ, стъпки | `data/site.ts` |
| Снимки и видео (hero рийл, презентация, формати) | `data/site.ts` → `media`, `formats[].image`; файлове в `public/media/` |
| PDF тарифа и спонсорски брошури | `public/downloads/` |
| Партньорски лога (ticker) | `data/site.ts` → `partners` (празно = скрито) |
| SEO / OpenGraph | `app/layout.tsx`; JSON-LD (`Organization`, `FAQPage`) в `app/page.tsx` |

## Форма за запитване

`POST /api/inquiry` валидира данните и ги препраща към `INQUIRY_WEBHOOK_URL` (вижте `.env.example`).
Ако променливата не е зададена, формата отваря имейл приложението на посетителя с попълнено писмо до рекламния отдел.

## Дизайн и анимации

Тъмна тема (цветовете са токени в `app/globals.css`) със златния акцент от логото.

Анимациите са във Framer Motion с Apple-подобна крива `cubic-bezier(0.22, 1, 0.36, 1)`, а скролът е с инерция (Lenis):

- hero, който остава закован при скрол, а кадърът от студиото се свива в заоблена рамка;
- гигантски надпис „В цяла България.“, през който камерата сякаш минава;
- заглавия, чиито думи се изнасят нагоре изпод маска, и карти, които се изправят в перспектива;
- броячи, „прожектор“ под курсора, хоризонтална галерия на форматите, изречение, което светва дума по дума,
  мащабиране на видеото, изчертаваща се линия в стъпките и плавни акордеони.

При `prefers-reduced-motion: reduce` плавният скрол и скрол ефектите се изключват, галерията става обикновен списък,
а `MotionConfig reducedMotion="user"` оставя само смяна на прозрачност.
